# C++ Module 04: 서브타입 다형성, 추상 클래스, 인터페이스

이 모듈은 C++의 객체 지향 프로그래밍(OOP) 핵심 개념인 다형성(Polymorphism), 추상 클래스(Abstract Class), 그리고 인터페이스(Interface)를 다룹니다.

## 개요

- **Exercise 00: 다형성 (Polymorphism)**
  - `Animal` 기본 클래스와 이를 상속받는 `Dog`, `Cat` 클래스를 구현합니다.
  - `virtual` 키워드를 사용하여 실행 시간에 적절한 함수가 호출되는 **동적 바인딩(Dynamic Binding)**을 학습합니다.
  - `WrongAnimal`과 `WrongCat`을 통해 `virtual`이 없을 때 발생하는 문제(정적 바인딩)를 확인합니다.

- **Exercise 01: 뇌가 있는 동물 (I don't want to set the world on fire)**
  - `Brain` 클래스를 도입하여 `Dog`와 `Cat`이 개별적인 뇌를 가지도록 합니다.
  - **깊은 복사(Deep Copy)**의 중요성을 학습합니다. 복사 생성자와 복사 대입 연산자에서 메모리를 새로 할당하여 객체 간의 독립성을 보장해야 합니다.
  - 소멸자가 호출될 때 메모리 누수가 발생하지 않도록 관리합니다.

- **Exercise 02: 추상 클래스 (Abstract class)**
  - `Animal` 클래스를 직접 인스턴스화하는 것은 논리적으로 어색합니다 (단순히 '동물'인 생명체는 없기 때문).
  - 순수 가상 함수(Pure Virtual Function)를 사용하여 클래스를 **추상 클래스**로 만듭니다. 이로 인해 `Animal` 객체는 생성할 수 없으며, 반드시 상속받은 자식 클래스를 통해서만 사용할 수 있습니다.

- **Exercise 03: 인터페이스와 요약 (Interface & recap)**
  - C++98에는 별도의 `interface` 키워드가 없지만, 순수 가상 함수만으로 이루어진 추상 클래스를 통해 인터페이스를 구현합니다.
  - `AMateria`, `ICharacter`, `IMateriaSource` 등을 통해 복잡한 객체 간의 상호작용과 메모리 관리(인벤토리 시스템)를 연습합니다.

## 핵심 개념 정리

### 1. 다형성 (Polymorphism)
하나의 인터페이스(기본 클래스)를 통해 여러 가지 실제 구현(파생 클래스)을 동일한 방식으로 다루는 능력입니다. `virtual` 함수를 사용하면 포인터나 참조자가 가리키는 실제 객체의 타입에 맞는 함수가 호출됩니다.

### 2. 가상 소멸자 (Virtual Destructor)
기본 클래스의 포인터로 자식 객체를 삭제할 때, 자식 클래스의 소멸자가 정상적으로 호출되게 하려면 반드시 기본 클래스의 소멸자를 `virtual`로 선언해야 합니다. 그렇지 않으면 메모리 누수의 원인이 됩니다.

### 3. 깊은 복사 vs 얕은 복사
- **얕은 복사 (Shallow Copy)**: 포인터 주소값만 복사하여 두 객체가 같은 메모리를 공유하게 됩니다. 한쪽에서 메모리를 해제하면 다른 쪽은 댕글링 포인터(Dangling Pointer)가 됩니다.
- **깊은 복사 (Deep Copy)**: 실제 데이터를 위한 새로운 메모리를 할당하고 내용을 복사합니다. 각 객체는 자신만의 데이터를 가집니다.

### 4. 추상 클래스와 인터페이스
- **추상 클래스**: 하나 이상의 순수 가상 함수(`virtual void func() = 0;`)를 포함한 클래스입니다. 직접 객체를 만들 수 없습니다.
- **인터페이스**: 멤버 변수 없이 오직 순수 가상 함수로만 구성된 클래스입니다. 자식 클래스가 특정 기능을 반드시 구현하도록 강제하는 '계약' 역할을 합니다.
